# terrychendev

Personal portfolio site. Plain HTML/CSS/JS, no build step.

- `index.html` — page markup
- `css/style.css` — styles
- `js/blackhole.js` — the WebGL black hole on the front page

Run locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. Add `?still=6` to the URL to render a single frozen frame (handy for screenshots).
